# Decisioni

1. Locale prima del cloud: Room resta la fonte operativa durante assenza di rete.
2. Eventi append-only: audit e correzioni mantengono la storia.
3. `BigDecimal`: dosi frazionarie e scorte non subiscono arrotondamenti binari.
4. `AlarmManager`: i promemoria clinici richiedono orari esatti; l’app mostra la diagnostica del permesso.
5. `drive.file`: accesso minimo e verifica OAuth più contenuta.
6. REST v3: evita un SDK Drive Android dismesso e mantiene esplicito il protocollo.
7. File cifrati per paziente: un grant può revocare un singolo profilo senza condividere un archivio globale.
